# Fonts

`Heebo-Regular.ttf`: Heebo Regular, version 3.100, static TTF (not the variable font).
Copyright 2014 The Heebo Project Authors (https://github.com/OdedEzer/heebo). Licensed under the
SIL Open Font License 1.1: see `OFL.txt` next to this file. Embedding it in PDFs is allowed.

Taken from the npm package `@expo-google-fonts/heebo@0.4.2` (file `400Regular/Heebo_400Regular.ttf`,
SHA-256 `0e104baeec4972ed144d65e0cda202db4667037f4da23255e40490a9dc9f0ccb`). It is a file in the
repo, not a dependency.

Used for all text drawn on PDFs (task 3.6): one font for Hebrew and Latin, so names, addresses,
phones and emails share it. Embedded as a subset in each PDF.
